# IN-12 / IV-22 cutting/mask board

Template for drilling/cutting your own case. Based on the IV-22 board, but with no tracks, solder, etc.

The original version is Gerber files because I like making PCB manufacturers suffer.
Something aluminum-based with a thickness of 1.4mm should work well.

Since CNC and laser machines like .dxf files, I did a .dxf conversion as well. It is strictly 2D so
you'll have to generate depth files yourself.
